# Exports

Generated by `scripts/build_exports.py`; do not edit by hand. Stable URLs under `https://mmccalla.github.io/nist-attack-enterprise-ontology/exports/`.

| File | Content |
| --- | --- |
| `claims.csv` | Every mitigation claim: control, technique, tactics, control baselines and the source record numbers behind it |
| `techniques.csv` | Every active ATT&CK Enterprise 16.1 technique with its mitigating controls and mapping status (`claims`, `non_mappable`, `no_row`) |
| `controls.csv` | Every mapped control with its OSCAL id, baselines and number of techniques mitigated |
| `navigator/baseline-*.json` | ATT&CK Navigator layers (format 4.5) for the LOW, MODERATE, HIGH and PRIVACY baselines |
| `navigator/all-controls.json` | Navigator layer scored by the number of mapped controls per technique |
| `questions/cqNN.csv` | The answer to each competency question |
| `navigator/cis-all-safeguards.json` | Navigator layer (ATT&CK 19) for all CIS Safeguards in the CTID mapping |
| `cis-claims.csv` | Each CIS Safeguard and ATT&CK 19.1 technique claim, with source row numbers, the CTID rationale and references |
| `cis-8.1.2-safeguards.csv` | Each CIS 8.1.2 Safeguard: exact CIS title, Control, asset class, security function, Implementation Groups, AI guidance and the number of mapped techniques |
| `attack-16.1-to-20.1.csv` | Each ATT&CK 16.1 technique that ATT&CK 20.1 revokes, renames or moves, with its replacement, new name, new tactics and claims |
| `atlas-techniques.csv` | Each MITRE ATLAS 2026.10 technique: the agent flag (derived by this project), maturity, parent, ATLAS mitigations and the ATT&CK technique it cites |
| `atlas-mitigations.csv` | Each MITRE ATLAS 2026.10 mitigation: categories and techniques |
| `owasp-llm-atlas-links.csv` | Each ATLAS ID that OWASP links to an LLM Top 10 (2025) risk, and whether ATLAS 2026.10 has it |

Each Navigator layer holds the ATT&CK notice and a link to the notices in its metadata.

In the Navigator layers, green cells are covered (darker means more controls), amber cells are gaps a mapped control outside the selection would close, and grey cells have no mitigating control in the mapping. Each cell's comment names the controls.
